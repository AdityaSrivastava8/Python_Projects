## 5. Tokenization

```python
tokens = word_tokenize(text)
```

Tokenization is the process of breaking a large piece of text (sentence, paragraph, or document) into smaller units called tokens. These tokens are usually words, punctuation marks, or sentences.

Example:

```
The government announced a new policy.
```

becomes

```
["The", "government", "announced", "a", "new", "policy", "."]
```

---

## 6. Stopwords

Stopwords are common words in a language (such as the, is, a, an, and, of, to) that occur frequently but usually add little meaning to the text. They are removed during preprocessing to focus on important words.

Examples:

```
the
is
a
an
of
to
and
```

Removing them reduces unnecessary data.

## 8. Stemming

```python
PorterStemmer()
```

Stemming is the process of reducing a word to its root (stem) form by removing prefixes or suffixes. This helps treat different forms of the same word as a single word.

Examples:

```
playing → play
running → run
studies → studi
```

Purpose:

* Reduce vocabulary size
* Improve model efficiency

---

## 9. TF-IDF

TF-IDF is a text vectorization technique that converts words into numerical values based on how important they are in a document relative to the entire dataset. It helps machine learning models identify the most significant words.

```python
TfidfVectorizer()
```

### Full Form

**Term Frequency – Inverse Document Frequency**

Computers cannot understand text directly.

TF-IDF converts words into numbers.

### Term Frequency (TF)

Measures how frequently a word appears in a document.

### Inverse Document Frequency (IDF)

Reduces the importance of words that appear in almost every document.

Example:

```
government → high importance
the → low importance
```

---

## 10. Feature Vector

A feature vector is a numerical representation of data, where each value represents a feature used by a machine learning model for training and prediction.

After TF-IDF,

```
"The government announced policy"
```

might become

```
[0.12 0.00 0.84 0.35 ...]
```

This numerical representation is called a **feature vector**.

## 15. Naive Bayes 

Naive Bayes is a supervised machine learning algorithm based on Bayes' Theorem that classifies data by selecting the class with the highest probability.

Example:

```
Scientists discovered new medicine
```

↓

```
Probability(Real) = 0.91
Probability(Fake) = 0.09
```

Prediction:

```

```

---

## 16. Why "Naive"?

It assumes every word is independent.

Example:

```
new
medicine
```

are treated independently even though they are related.

This assumption is "naive," but it works well for many text classification problems.
