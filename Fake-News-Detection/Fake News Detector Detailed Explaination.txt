## 1. Natural Language Processing (NLP)

**Definition:**

* Removing unnecessary words

## 5. Tokenization

tokens = word_tokenize(text)

Tokenization is the process of breaking a large piece of text (sentence, paragraph, or document) into smaller units called tokens. These tokens are usually words, punctuation marks, or sentences.

Example:

The government announced a new policy.

becomes

["The", "government", "announced", "a", "new", "policy", "."]

---

## 6. Stopwords

Stopwords are common words in a language (such as the, is, a, an, and, of, to) that occur frequently but usually add little meaning to the text. They are removed during preprocessing to focus on important words.

Examples:

the
is
a
an
of
to
and

Removing them reduces unnecessary data.

---

## 7. Stopword Removal

filtered = [word for word in tokens if word.lower() not in stop_words]

Example

Before:

The government announced a new policy

After:

government announced new policy

---

## 8. Stemming

PorterStemmer()

Stemming is the process of reducing a word to its root (stem) form by removing prefixes or suffixes. This helps treat different forms of the same word as a single word.

Examples:

playing → play
running → run
studies → studi

Purpose:

* Reduce vocabulary size
* Improve model efficiency

---

## 9. TF-IDF

TF-IDF is a text vectorization technique that converts words into numerical values based on how important they are in a document relative to the entire dataset. It helps machine learning models identify the most significant words.

TfidfVectorizer()

### Full Form

**Term Frequency – Inverse Document Frequency**

Computers cannot understand text directly.

TF-IDF converts words into numbers.

### Term Frequency (TF)

Measures how frequently a word appears in a document.

### Inverse Document Frequency (IDF)

Reduces the importance of words that appear in almost every document.

Example:

government → high importance
the → low importance

---

## 10. Feature Vector

A feature vector is a numerical representation of data, where each value represents a feature used by a machine learning model for training and prediction.

After TF-IDF,

"The government announced policy"

might become

[0.12 0.00 0.84 0.35 ...]

This numerical representation is called a **feature vector**.

## 15. Naive Bayes

## 16. Why "Naive"?

It assumes every word is independent.

Example:

medicine

are treated independently even though they are related.

This assumption is "naive," but it works well for many text classification problems.

Fake News Detection Code – One-Line Explanation for Each Step

1. import nltk – Imports the NLTK library for Natural Language Processing (NLP). NLTK (Natural Language Toolkit) is a popular Python library used for Natural Language Processing (NLP). It provides tools for processing, analyzing, and understanding human language (text). 
     
2. nltk.download(‘punkt’) – Punkt is a pre-trained sentence and word tokenizer provided by NLTK. It helps split text into sentences and words while correctly handling punctuation and abbreviations.
    
3. nltk.download(‘punkt_tab’) – nltk.download('punkt_tab') downloads the Punkt tokenizer language tables, an additional resource required by newer versions of NLTK for tokenization. It            works together with punkt to provide the language-specific rules needed by functions such as word_tokenize(). Without this resource, tokenization may fail and produce a LookupError: Resource 'punkt_tab' not found. Downloading punkt_tab ensures that NLTK can accurately split text into words and sentences, making it an essential dependency for many Natural Language Processing (NLP) tasks.

4. nltk.download(‘stopwords’) – downloads the Stopwords corpus from NLTK, which contains lists of commonly used words for different languages, including English. These words (such as the, is, a, an, and, of, to) appear very frequently in text but usually contribute little to the overall meaning. During text preprocessing, these stopwords are removed to reduce noise, decrease the size of the data, and improve the efficiency and accuracy of machine learning models. In your Fake News Detection project, the downloaded stopwords are used to filter out unnecessary words before converting the text into feature vectors.

5. import pandas as pd – This statement imports the Pandas library and assigns it the alias pd. Pandas is a powerful Python library used for data manipulation, analysis, and handling structured data such as CSV, Excel, and SQL files. Using the alias pd is a standard Python convention that makes the code shorter and easier to write. In your Fake News Detection project, Pandas is used to load the dataset, access rows and columns, and prepare the data before preprocessing and machine learning.

6. df = pd.read_csv(“fake_news.csv”) – This statement reads the fake_news.csv file using Pandas and stores its contents in a DataFrame named df. The read_csv() function loads the dataset from the CSV file, where each row represents a news article and each column represents an attribute such as Title, Text, and Label. Once loaded, the DataFrame allows you to access, manipulate, and analyze the data easily for preprocessing and machine learning.

7. print(df.head()) – This statement displays the first five rows of the DataFrame df. The head() function is used to quickly preview the dataset after loading it, allowing you to verify that the data has been imported correctly and to inspect the column names, data types, and sample records before performing preprocessing or machine learning.

8. from nltk.tokenize import word_tokenize – This statement imports the word_tokenize() function from NLTK's tokenize module. The word_tokenize() function is used to split a sentence or paragraph into individual words and punctuation marks called tokens. It is one of the most commonly used tokenization methods in Natural Language Processing (NLP) and serves as the first step in text preprocessing.

9. text = df.loc[0, “Text”] – This statement uses the loc[] function of a Pandas DataFrame to access a specific value from the dataset. It selects the first row (0) and the Text column, then stores the news article in the variable text. This text is later used for NLP preprocessing steps such as tokenization, stopword removal, and stemming.

10. tokens = word_tokenize(text) – This statement uses the word_tokenize() function to split the text stored in the variable text into individual words and punctuation marks called tokens. The resulting tokens are stored in the variable tokens as a Python list. Tokenization is the first step in text preprocessing and prepares the text for further NLP tasks such as stopword removal, stemming, and text classification.

11. print(tokens) – This statement displays the list of tokens generated by the word_tokenize() function. It prints each word and punctuation mark as a separate element in the output, allowing you to verify that the text has been tokenized correctly. This step is useful for checking the preprocessing results before applying further NLP techniques such as stopword removal and stemming.

12. from nltk.corpus import stopwords – This statement imports the stopwords corpus from the NLTK library. The stopwords corpus contains predefined lists of commonly used words for many languages, including English. These words (such as the, is, a, an, and, of, to) appear very frequently in text but usually do not carry significant meaning. By importing stopwords, you can easily access these word lists and remove them during text preprocessing, improving the efficiency and accuracy of NLP and machine learning models.

13. stop_words = set(stopwords.words(“english”)) – This statement retrieves the list of English stopwords from the NLTK stopwords corpus and converts it into a set, storing it in the variable stop_words. Using a set allows for faster word lookup compared to a list, making the process of checking and removing stopwords more efficient. These stopwords are later used to filter out common words such as the, is, a, and, of, which usually do not contribute much to the meaning of the text.

With a list, Python may compare each word against many stopwords, making preprocessing slower.
With a set, Python finds whether the word exists almost instantly, making preprocessing much faster.

14. filtered = [word for word in tokens if word.lower() not in stop_words] – This statement uses list comprehension to create a new list called filtered by removing all stopwords from the tokenized text. It checks each word in the tokens list, converts it to lowercase using lower(), and keeps only those words that are not present in the stop_words set. As a result, the output contains only the meaningful words that are useful for further NLP tasks such as stemming, vectorization, and machine learning.

15. print(filtered) – Displays the filtered words after stopword removal.

16. from nltk.stem import PorterStemmer – This statement imports the PorterStemmer class from NLTK's stem module. PorterStemmer is one of the most widely used stemming algorithms in Natural Language Processing (NLP). It reduces words to their root (stem) form by removing prefixes and suffixes. This helps treat different forms of the same word as a single word, reducing the vocabulary size and improving the efficiency of text analysis and machine learning models.

17. stemmer = PorterStemmer() – This statement creates an object (instance) of the PorterStemmer class and stores it in the variable stemmer. The object is then used to access the stem() method, which converts words into their root (stem) form. Without creating this object, you cannot use the stemming functionality provided by the PorterStemmer class.

18. stemmed = [stemmer.stem(word) for word in filtered] – This statement uses list comprehension to apply stemming to every word in the filtered list. For each word, the stem() method of the PorterStemmer object is called, converting the word to its root (stem) form. The resulting stemmed words are stored in a new list called stemmed. This process reduces different forms of the same word to a common base form, making text analysis and machine learning more efficient.

19. print(stemmed) – Displays the stemmed words.

20. from sklearn.feature_extraction.text import TfidfVectorizer – This statement imports the TfidfVectorizer class from Scikit-learn's feature_extraction.text module. TfidfVectorizer is used to convert text into numerical feature vectors using the TF-IDF (Term Frequency–Inverse Document Frequency) technique. Since machine learning models cannot understand text directly, TF-IDF transforms each document into a vector of numbers that represents the importance of each word. Words that occur frequently in a document but are rare across the dataset receive higher weights, while very common words receive lower weights.

21. vectorizer = TfidfVectorizer(stop_words=“english”) – This statement creates an object of the TfidfVectorizer class and stores it in the variable vectorizer. The parameter stop_words="english" automatically removes common English stopwords (such as the, is, a, and, of) while converting the text into TF-IDF feature vectors. Removing these common words helps the model focus on more meaningful words, reduces noise in the data, and often improves the performance of text classification.

22. X = vectorizer.fit_transform(df[“Text”]) – This statement converts all the news articles in the Text column into TF-IDF feature vectors and stores the result in the variable X. The fit_transform() method performs two operations in one step: first, it learns the vocabulary and calculates the TF-IDF scores from the dataset (fit), and then it transforms each news article into a numerical feature vector (transform). These vectors become the input features for the machine learning model.

23. y = df[“Label”] – This statement selects the Label column from the DataFrame df and stores it in the variable y. The Label column contains the target values (output) for the machine learning model. In your Fake News Detection project, each label indicates whether a news article is Real or Fake. During model training, the algorithm learns the relationship between the input features (X) and these output labels (y) so that it can correctly classify new, unseen news articles.

24. from sklearn.model_selection import train_test_split – This statement imports the train_test_split() function from Scikit-learn's model_selection module. This function is used to split the dataset into two parts: a training set and a testing set. The training set is used to teach the machine learning model, while the testing set is used to evaluate how well the trained model performs on unseen data. Splitting the data helps prevent overfitting and provides a fair estimate of the model's performance.

Underfitting: A model that is too simple and fails to learn the training data properly.
Best Fit: A model that learns the underlying patterns and performs well on both training and unseen data.
Overfitting: A model that memorizes the training data and performs poorly on new, unseen data.

25. train_test_split(…) – Divides the dataset into training (80%) and testing (20%) sets. The train_test_split() function divides the dataset into two parts: a training set and a testing set. The training set is used to teach the machine learning model, while the testing set is used to evaluate how well the trained model performs on unseen data. This ensures that the model is tested on data it has never seen before, providing a reliable measure of its performance. The 80% training / 20% testing split is not a strict rule, but it is the most commonly used ratio because it provides a good balance between learning and evaluation.

26. from sklearn.naive_bayes import MultinomialNB – This statement imports the MultinomialNB class from Scikit-learn's naive_bayes module. Multinomial Naive Bayes is a supervised machine learning algorithm commonly used for text classification tasks such as fake news detection, spam email detection, sentiment analysis, and document classification. It applies Bayes' Theorem to calculate the probability of each class (e.g., Real or Fake) based on the words present in the text and predicts the class with the highest probability.

Why is MultinomialNB used?
Text data converted using TF-IDF or CountVectorizer consists of word frequencies or weights. MultinomialNB is specifically designed to work with this type of data, making it one of the most popular algorithms for NLP classification tasks.

27. model = MultinomialNB() – This statement creates an object (instance) of the MultinomialNB class and stores it in the variable model. The object represents the Naive Bayes machine learning model that will later be trained using the training data. At this stage, the model has not learned anything—it is simply initialized and ready to be trained.

28. model.fit(X_train, y_train) – This statement trains the Multinomial Naive Bayes model using the training dataset. The fit() method takes the input features (X_train) and their corresponding labels (y_train) and learns the relationship between them. During training, the model analyzes the TF-IDF feature vectors and identifies patterns that distinguish Real news from Fake news. After training, the model can predict the class of new, unseen news articles.

29. from sklearn.metrics import accuracy_score – This statement imports the accuracy_score() function from Scikit-learn's metrics module. The accuracy_score() function is used to measure the performance of a machine learning model by calculating the percentage of correct predictions made by the model. It compares the actual labels (y_test) with the predicted labels (pred) and returns the model's accuracy as a value between 0 and 1 (or 0% to 100%).

30. pred = model.predict(X_test) – This statement uses the trained Multinomial Naive Bayes model to predict the labels of the testing data (X_test). The predict() method analyzes the TF-IDF feature vectors in X_test and assigns each news article a predicted label, such as Real or Fake. These predicted labels are stored in the variable pred, which is later compared with the actual labels (y_test) to calculate the model's accuracy.

31. print(pred) – Displays the predicted labels.

32. print(“Accuracy:”, accuracy_score(y_test, pred)) – This statement calculates the accuracy of the machine learning model using the accuracy_score() function and prints the result. The function compares the actual labels (y_test) with the predicted labels (pred) and returns the proportion of correctly classified news articles. The accuracy value ranges from 0 to 1, where 1 (100%) means all predictions are correct and 0 means none are correct.

33. new_news = input(“Enter a news article:”) – Accepts a new news article from the user.

34. new_vec = vectorizer.transform([new_news]) – This statement converts the new news article entered by the user into a TF-IDF feature vector using the same vocabulary learned during training. Unlike fit_transform(), the transform() method does not learn any new words; it simply converts the input text into numerical features based on the existing vocabulary. The resulting feature vector is stored in the variable new_vec, which is then used by the trained machine learning model to make a prediction.

35. prediction = model.predict(new_vec)[0] – This statement uses the trained Multinomial Naive Bayes model to predict the class of the new news article represented by the TF-IDF vector new_vec. The predict() method returns a list (or NumPy array) containing the predicted label(s). Since only one news article is being classified, the result contains a single element. The index [0] is used to extract that first (and only) prediction and store it in the variable prediction.

36. print(“Prediction:”, prediction) – Displays the final prediction to the user.
